# Portfolio Site: Beta Version

## Description
This is a learning-focused <em>beta project</em> to practice front-end developing skills in HTML, CSS, and JS before building a formal portfolio site.

## Purpose
The end-goal of this portfolio is to document learning of JavaScript and experiment with photo galleries, embedding files, UI animation, and forms.

## Project Status
**Status:** Beta Project/Practice Build <br>
This is an experimental web development and design project.

**Current Files:**<br>
- <a href="/index.html">index.html</a> – main landing page (Home)
- <a href="/learning-js.html">learning-js.html</a> – feed page of JS example walkthroughs I want to remember
- <a href="/mystyles.css">mystyles.css</a> – style sheet for global and element-specific design
- <a href="/about.html">about.html</a> – about page w/ contact form
- <a href="resume.html">resume.html</a> – to be filled out -- hard-coded or pdf viewer
